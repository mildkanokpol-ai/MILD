# บัญชีรายเดือน — Android ออฟไลน์ 0.4

ข้อมูลทั้งหมดอยู่ในเครื่อง ไม่มี Gmail, Google Sheets, Claude หรือเซิร์ฟเวอร์ และไม่มีสิทธิ์ INTERNET ใน APK

## การอ่านสลิปและยอด Dashboard
1. เลือกเดือนที่ต้องการ แล้วกด “สแกนสลิปเดือนนี้” หรือกลับเข้าแอปเพื่อสแกนอัตโนมัติ
2. อนุญาตคลังภาพทั้งหมดเพื่อให้ตรวจครบ หากให้สิทธิ์บางรูปจะอ่านได้เฉพาะรูปที่อนุญาต
3. สลิปที่มีข้อความเงินออกชัดเจน ยอด วันที่ เวลา และไม่เข้าข่ายซ้ำ จะทยอยบันทึกเป็นรายจ่ายจริงระหว่างสแกนและอัปเดต Dashboard
4. ข้อความโอนสำเร็จทั่วไปยังยืนยันทิศทางเงินไม่ได้ จึงอยู่ใน “ดูสลิปรอตรวจ” เลือกสลิปที่เป็นเงินออกของคุณ ตรวจยอด/วันที่ แล้วกด “ยืนยันเงินออกที่เลือก” ยอดจะรวมใน Dashboard ทันที
5. หากยอดหรือวันที่อ่านไม่ได้ ให้กดสลิปเพื่อแก้รายรูป ช่องเลือกยืนยันรวมจะปิดไว้ หากอ่านเวลาไม่ได้ การยืนยันรวมใช้ 12:00
6. ระหว่างเปิดรายการรอตรวจ กด “อัปเดตรายการ” เพื่อดูรูปที่เพิ่งอ่านเพิ่มโดยไม่รบกวนการเลือกเดิมระหว่างสแกน

## ความเร็วและข้อจำกัด
- ส่งผลเป็นชุดย่อยระหว่างอ่าน ใช้แคชสำหรับรูปเดิมและไฟล์สำเนาที่มีเนื้อหาเหมือนกัน ลดการอ่านซ้ำและการอัปเดตสถานะถี่เกินไป
- รอบแรกยังต้อง OCR รูปที่ไม่เคยอ่าน ความเร็วขึ้นกับจำนวน/ขนาดรูปและโทรศัพท์ ยังไม่มีผลจับเวลาบนเครื่องผู้ใช้
- ค้นภาพจากวันที่ถ่ายหรือวันที่เพิ่มเข้าคลังในเดือนที่เลือก แล้วตรวจเดือนจากข้อความบนสลิป รูปที่มีวันที่ทั้งสองอยู่นอกเดือนจะไม่ถูกเลือก
- OCR ไทย/อังกฤษอาจอ่านยอด วันที่ หรือทิศทางเงินผิด ตรวจรายการและแก้ไขได้ ไม่รับประกันการอ่านทุกธนาคาร
- รูปที่บันทึกแล้วจะไม่เพิ่มซ้ำจากไฟล์เดิม รูปที่ครอปหรือถ่ายใหม่อาจมีรหัสภาพต่างกัน รายการที่อาจซ้ำจะรอตรวจ อย่ายืนยันซ้ำเอง
- การยืนยันรวมเก็บรายการและข้อความอ้างอิง แต่ไม่ได้คัดลอกรูปต้นฉบับแนบรายการ การตรวจและบันทึกทีละรูปสามารถแนบภาพได้
- ทำงานขณะเปิดแอป ไม่มีบริการสแกนเบื้องหลังปิดแอป ไม่มี cloud sync

## ติดตั้งและสำรอง
Android 8 ขึ้นไป โปรไฟล์ → สำรอง JSON พร้อมรูป ก่อนถอนติดตั้งหรือล้างข้อมูล นำเข้าจะแทนข้อมูลทั้งหมด
รุ่นนี้เป็น debug APK จาก GitHub Actions กุญแจเซ็นอาจต่างจากรุ่นก่อน หากติดตั้งทับไม่ได้ ต้องสำรองและตรวจว่าได้ไฟล์ก่อนถอนรุ่นเก่า แล้วติดตั้งรุ่นใหม่และนำเข้าสำรอง

## สร้างและทดสอบ
ซอร์สหลักอยู่ใน app/src/main/assets และ app/src/main/java ไม่รันตัวสร้างรุ่นเก่าทับ
GitHub Actions ติดตั้ง Java 17 / Gradle 8.11.1 รันทดสอบ logic, IndexedDB และ UI ด้วย jsdom สร้าง APK และ lint ตรวจไม่มีสิทธิ์ INTERNET และมีโมเดล OCR ไทย/อังกฤษใน APK
ใช้ node tools/models.cjs ดาวน์โหลดโมเดลจาก tessdata_fast 4.1.0 เฉพาะตอน build
ทดสอบบนโทรศัพท์: สแกนเดือนที่มีสลิป → ยืนยันรายการรอตรวจ → ตรวจรายจ่าย/กราฟ → สแกนซ้ำยอดไม่เพิ่ม → เปลี่ยนเดือน → ปิดเปิดแอปยอดยังอยู่
