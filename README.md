# มันนี่ — รุ่น 0.5 วิดเจ็ต / ออฟไลน์

## เปลี่ยนแปลง
- เปลี่ยนชื่อที่ไอคอนแอป หน้าแอป และรายการวิดเจ็ตเป็น มันนี่
- เอาระบบสแกนสลิปอัตโนมัติและอ่านสลิปทีละรูปออก ไม่ขอสิทธิ์อ่านทั้งคลังภาพ ไม่มี OCR หรือโมเดลภาษาใน APK
- ยังเลือกรูปโปรไฟล์และแนบรูปในรายการที่กรอกเองได้ ผ่านตัวเลือกไฟล์ของ Android ไม่อ่านยอดจากภาพ
- เพิ่มวิดเจ็ตสรุปรายรับ รายจ่าย ยอดสุทธิของเดือน และแถบสัดส่วนรายจ่ายต่อรายรับ
- ปรับแต่ละวิดเจ็ตได้: น้ำเงินทอง/ดำทอง/สว่าง, เดือนปัจจุบันอัตโนมัติหรือระบุเดือน, ซ่อนยอด, แบบกะทัดรัด
- กดค้างเพื่อย่อขยายตามขนาดที่ Launcher รองรับ แตะยอดเพื่อเปิดแอป แตะเฟืองเพื่อแก้การตั้งค่า
- ยังคง package ID และฐานข้อมูลเดิม รองรับข้อมูลสำรอง JSON จากรุ่นเก่า ไม่เปลี่ยนยอดรายการที่เคยบันทึก

## เพิ่มวิดเจ็ต
1. เปิดแอปและโหลดข้อมูลหนึ่งครั้ง
2. แตะ ▦ ด้านบน → เพิ่มวิดเจ็ต หาก Launcher รองรับจะมีคำขอยืนยัน
3. หากไม่ขึ้น กดค้างพื้นที่ว่างบนหน้าจอโฮม → วิดเจ็ต → มันนี่ → ลากวาง
4. เลือกธีมและเดือน แล้วกดบันทึก หากเพิ่มโดยตรงได้ค่าเริ่มต้น ให้แตะ ⚙ เพื่อปรับ
5. ใส่ได้หลายวิดเจ็ต ตั้งค่าต่างกันได้

## ข้อมูลและข้อจำกัด
- อัปเดตวิดเจ็ตหลังโหลด บันทึก แก้ไข ลบรายการ หรือนำเข้าข้อมูลสำรองในแอป เก็บเฉพาะผลรวมรายเดือนในเครื่องเพื่อให้ดูได้ตอนปิดแอป
- ยอดสุทธิ = รายรับ − รายจ่าย ไม่ใช่ยอดธนาคาร ไม่รวมรายการคาดการณ์ ออม หรือโอนระหว่างบัญชีเป็นรายรับรายจ่ายซ้ำ
- วิดเจ็ตใช้ผลจากการเปิดแอปล่าสุด รายการประจำจะประมวลผลเมื่อเปิดแอป แสดงเวลาข้อมูลล่าสุดไว้
- เดือนปัจจุบันเปลี่ยนตามเวลาไทย รอบอัปเดตโดย Android ประมาณ 30 นาทีขึ้นไป อาจช้าตามการประหยัดพลังงาน
- ไม่มีการเชื่อมอินเทอร์เน็ต ไม่มี Google Cloud หรือค่าบริการอ่านสลิป
- รูปแบบและขนาดจริงขึ้นกับ Launcher และขนาดตัวอักษร เครื่องมือทดสอบยืนยัน logic, หน้าแอป, การ build และ lint ยังไม่ได้ยืนยันหน้าจอโฮมบนโทรศัพท์ผู้ใช้

## สำรองก่อนอัปเดต
ไปโปรไฟล์ → สำรอง JSON พร้อมรูป ตรวจว่าได้ไฟล์ก่อนถอนแอปหรือล้างข้อมูล
APK จาก GitHub Actions ยังใช้ debug signing ซึ่งอาจคนละกุญแจกับรุ่นก่อน ถ้าติดตั้งทับไม่ได้ ให้สำรองก่อนถอนรุ่นเดิม แล้วติดตั้งใหม่และนำเข้า JSON

## สำหรับพัฒนา
ซอร์สหลักใน app/src/main/assets และ app/src/main/java ห้ามใช้ตัวสร้างรุ่นเก่าทับ
node tests/offline.cjs และ node tests/ui.cjs (ต้องมี fake-indexeddb/jsdom)
gradle :app:assembleDebug :app:lintDebug
python3 tools/apk-check.py ตรวจ manifest ว่าไม่มี INTERNET หรือสิทธิ์อ่านภาพ และไม่มี OCR model
ไฟล์ tools/models.cjs เป็นคำสั่งว่างเพื่อรองรับ workflow เก่า ไม่ดาวน์โหลดอะไร
